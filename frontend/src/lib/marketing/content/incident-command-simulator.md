## Practice incident command before the incident

Incident command gets better with repetition. Firefighters and officers need chances to take in changing conditions, make decisions, communicate assignments, and keep the incident organized.

3AlarmLabs gives firefighters an incident command simulator built around practical command reps: start a scenario, work the incident, and review the run afterward.

## What an incident command simulator should include

- A realistic scenario starting point
- Space to practice initial reports and follow-up radio traffic
- Company and unit assignment tracking
- A command board that keeps the incident understandable
- Replay review for coaching and self-assessment

## Who uses it

Incident command simulation is useful for company officers, acting officers, firefighters preparing to promote, training officers, academies, and departments that want more consistent officer development.

## Frequently asked questions

### Is this only for chief officers?

No. Incident command practice is useful for anyone preparing to lead, including acting officers, company officers, and firefighters preparing for promotion.

### Can I practice alone?

Yes. 3AlarmLabs supports self-paced command training so firefighters can practice without waiting for a scheduled instructor-led session.

### What happens after a scenario?

Each run can be reviewed so firefighters and instructors can discuss radio communication, assignments, decisions, and timing.
