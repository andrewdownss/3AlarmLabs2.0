## Practice command over the radio

Command training is not only about choosing the right tactic. Officers also need to communicate clearly enough for crews to understand assignments, priorities, and updates.

3AlarmLabs uses radio-based command reps so firefighters can practice how they sound while running a scenario.

## What radio practice improves

- Initial reports
- Company assignments
- Follow-up updates
- Command presence
- Concise communication under pressure

## Why capture radio traffic

Radio communication is easier to coach when it can be replayed. With transcripts and replay review, firefighters and instructors can talk through what was clear, what was late, and what should improve on the next run.

## Frequently asked questions

### Why practice push-to-talk commands?

Push-to-talk style practice helps firefighters build habits around clear, concise radio communication during command scenarios.

### Can radio traffic be reviewed?

Yes. 3AlarmLabs supports replay review so communication can be discussed after the scenario.

### Is this just for officers?

It is especially useful for officers and acting officers, but firefighters preparing to promote can benefit from radio command practice too.
