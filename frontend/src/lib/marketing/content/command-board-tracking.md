## Keep the training incident organized

Command board tracking helps firefighters see the incident as it develops. During training, it gives officers a way to practice assigning units, tracking actions, and maintaining situational awareness.

3AlarmLabs combines command scenarios with board-style organization so the run is easier to manage and easier to review.

## What a command board helps track

- Companies and assignments
- Tactical priorities
- Unit status and actions
- Incident progress
- Decisions made during the scenario

## Why it matters in training

Training should help firefighters build command discipline. A command board makes the thinking visible, which helps instructors coach organization, communication, and follow-through.

## Frequently asked questions

### Is command board tracking useful for self-paced training?

Yes. It helps firefighters stay organized while practicing command without an instructor beside them.

### Can instructors use the board for review?

Yes. The command board gives instructors a clearer picture of assignments and decisions during after-action review.

### Does this replace a physical command board?

No. It provides a digital way to practice similar organizational habits during scenario training.
