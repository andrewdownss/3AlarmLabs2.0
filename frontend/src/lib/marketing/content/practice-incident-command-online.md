## Online incident command practice for firefighters

Command skill improves when firefighters get more chances to make decisions. Online incident command practice makes those repetitions easier to fit into the week.

3AlarmLabs lets firefighters run self-paced command scenarios, practice radio communication, and review the run afterward.

## Why practice online

- Train without waiting for a scheduled drill
- Repeat scenarios to improve timing and communication
- Practice from home, the station, or between formal sessions
- Review decisions and radio traffic after each run

## A practical supplement to department training

Online command practice should support, not replace, live drills and instructor coaching. It gives firefighters more repetitions between department training days so live training can build on stronger decision-making habits.

## Frequently asked questions

### Can I practice incident command from home?

Yes. 3AlarmLabs is web-based, so individual firefighters can practice self-paced command scenarios online.

### Is online command training realistic?

It is useful when it focuses on realistic decisions: size-up, communication, assignments, and review. 3AlarmLabs is designed around those command skills.

### Can departments assign online practice?

Yes. Department plans can support self-paced member practice and instructor-led sessions.
